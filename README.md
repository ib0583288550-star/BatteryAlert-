# התרעת סוללה · Battery Alert

אפליקציית Android בעברית שמתריעה כשהסוללה יורדת ל־15%, 10% ו־5%.

## מה כלול
- מסך בעברית בעיצוב כהה מודרני.
- התרעות מערכת עם צליל ורטט בשלוש רמות הסוללה.
- מעקב ברקע באמצעות שירות קדמי.
- הפעלה מחדש של המעקב לאחר אתחול המכשיר.
- מתג להפעלה והשהיה של המעקב.
- אייקון ייעודי וקרדיט y.b apps.

## בניית APK
GitHub Actions מפעיל בנייה אוטומטית בכל push לענף הראשי. בסיום מוצג artifact בשם `BatteryAlert-debug` באזור Actions של המאגר.

## תאימות
Android 6.0 ומעלה; בקשת הרשאת התראות נדרשת ב־Android 13 ומעלה.
